A tokenized asset is a stack of dependencies, not a single contract address. The Asset Dependency Engine walks that stack from the token you hold down to what finally backs it, and records every layer it passes as a node in one graph. Risk, treasury and compliance teams use it to see what a token really depends on before they hold it, list it or accept it as collateral.

## What it answers

| Question | Answer |
| --- | --- |
| What does this token actually depend on? | Everything under it: the vault, the underlying token, the oracle pricing it, the bridge it crossed, the legal wrapper and the collateral at the bottom. |
| How far down does it look? | It resolves recursively to depth 16. A branch ends only at native ETH, attested off-chain backing or a plain ERC-20 read. |
| What if it can't read a layer? | The layer still appears, as a flagged node with a reason. The graph is complete about what it doesn't know. |
| Does it score risk? | No. It shows what an asset depends on and lets you judge. |
