Disclosure Monitoring re-reads every tracked source for the assets you watch, keeps each version and tells you when something changes. Every change arrives classified for materiality, with the text before and after, the verbatim quote and the hash of the version read. Compliance desks, risk teams and allocators use it so they don't have to re-read issuer documents by hand.

## What it watches

| Monitor | What changes it catches |
| --- | --- |
| Disclosure field | A disclosed fact changes, is newly disclosed or is withdrawn |
| Source document | A tracked document changes in substance |
| Licence / register | A licence or register status changes |
| Sanctions screening | A screening result matches a sanctions list |
| Named parties | A named party, such as a custodian or auditor, changes |
| Collateral ISIN | A collateral instrument is linked |
