Bluprynt gives integrators three surfaces. Use the [KYI Widget SDK](/sdk/overview) to verify issuers inside your product. Use the [Public API](/api/public/overview) to read verified asset records and badges. Use the [Explorer API](/api/explorer/overview) to read tokenomics changes and run a [Disclosure Monitoring](/tools/disclosure-monitoring) watchlist.

## Choose a surface

| Surface | Use it to | Credential | Writes |
|---|---|---|---|
| **KYI Widget SDK** | Verify an issuer and its assets in your product | Partner ID + `SECRET_KEY` mint a short-lived token on your server | The member's own KYB, assets and wallet signatures |
| **Public API** | Show whether a token is KYI verified | API key, raw in `Authorization` | Nothing, every route is `GET` |
| **Explorer API** | Track tokenomics and disclosure changes | `bx_live_…` key as `Bearer` | Only the `watchlist:write` routes |

Base URLs: the SDK ships as `@bluprynt/kyi-widget-sdk`, the Public API is at `https://integrations.bluprynt.com` and the Explorer API is at `https://explorer-api.bluprynt.com`. For SDK partner credentials, ask your Bluprynt representative. For API keys, write to [product@bluprynt.com](mailto:product@bluprynt.com).

<Warning>
The two APIs authenticate differently. The Public API rejects a `Bearer` prefix. The Explorer API requires one.
</Warning>

## Authenticate

<Tabs>
  <Tab title="KYI Widget SDK" icon="app-window">
    Your server mints a token for the signed-in member, and the browser opens the drawer with it. The full server code is in [Access tokens](/sdk/tokens).

    ```ts
    // server
    import { generateToken } from '@bluprynt/kyi-widget-sdk/server'

    const accessToken = await generateToken({
      issuer: process.env.KYI_PARTNER_ID!,
      secretKey: process.env.KYI_SECRET_KEY!,
      userId: String(session.user.id),
    })

    // browser
    import { kyi } from '@bluprynt/kyi-widget-sdk'

    const widget = kyi('drawer', 'kyi', accessToken, {
      onClose: () => widget.destroy(),
    })
    ```
  </Tab>
  <Tab title="Public API" icon="plug">
    <CodeGroup>
    ```bash curl
    curl -s "https://integrations.bluprynt.com/assets/solana/EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v" \
      -H "Authorization: $BLUPRYNT_API_KEY"
    ```
    ```ts TypeScript
    const res = await fetch(
      'https://integrations.bluprynt.com/assets/solana/EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v',
      { headers: { Authorization: process.env.BLUPRYNT_API_KEY! } },
    )
    const asset = await res.json()
    ```
    ```python Python
    import os, requests

    asset = requests.get(
        "https://integrations.bluprynt.com/assets/solana/EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v",
        headers={"Authorization": os.environ["BLUPRYNT_API_KEY"]},
    ).json()
    ```
    </CodeGroup>
  </Tab>

## Key routes

<Columns cols={2}>
  <div>
    **Public API**

    | Route | Returns |
    |---|---|
    | `GET /assets` | All verified assets, paged |
    | `GET /assets/{chain}/{account_address}` | One asset by chain name |
    | `GET /assets/{namespace}/{reference}/{account_address}` | One asset by CAIP-2 chain ID |
    | `GET /kyi/v1/tokens` | KYI verification for a token |
    | `GET /api/v1/badges/{credential_type}` | A badge image, no key needed |

    [Full Public API reference](/api/public/overview)
  </div>
  <div>
    **Explorer API**

    | Route | Scope |
    |---|---|
    | `GET /tokenomics/changes` | `tokenomics:read` |
    | `GET /assets/{id}/tokenomics/changes` | `tokenomics:read` |
    | `GET /me/watchlist` | `monitoring:read` |
    | `GET /me/monitoring/changes` | `monitoring:read` |
    | `GET /me/notifications` | `monitoring:read` |
    | `POST`, `PATCH`, `DELETE /me/watchlist…` | `watchlist:write` |

    [Full Explorer API reference](/api/explorer/overview)
  </div>
</Columns>

## Try it without a key

Badges need no key, so this call works as is:

```bash
curl -s -o kyi.svg -w "%{http_code} %{content_type}\n" \
  "https://integrations.bluprynt.com/api/v1/badges/kyi_verified?variant=full"
# 200 image/svg+xml
```

The Explorer API health check needs no key either: `curl -s https://explorer-api.bluprynt.com/health`.
