The Bluprynt Public API returns the verified record behind an asset: its issuer, the wallets with authority over it, and whether each one is verified. It serves exchanges, wallets, data providers and regulators that need evidence-backed asset facts without running KYI themselves.

```text Base URL
https://integrations.bluprynt.com
```

Every route is a read-only `GET`. There are no write endpoints.

## Endpoints

| Endpoint | Key needed | Returns |
|---|---|---|
| `GET /assets` | Yes | All verified assets, paged with `page_size` and `page_number`. |
| `GET /assets/{chain}/{account_address}` | Yes | One asset by chain name, such as `ethereum` or `solana`. |
| `GET /assets/{namespace}/{reference}/{account_address}` | Yes | One asset by CAIP-2 chain ID, such as `eip155/1`. |
| `GET /kyi/v1/tokens` | Yes | KYI verification for a token by CAIP-19, or by address with an optional chain. |
| `GET /api/v1/badges/{credential_type}` | No | A KYI or Proof of Collateral badge image. |

The two `/assets` lookups return the same record. The CAIP form also covers chains that have no short name, such as `eip155/98866` for Plume.

## Authenticate

Send your API key as the raw `Authorization` header value. Don't add a `Bearer` prefix: the API rejects it. Ask [product@bluprynt.com](mailto:product@bluprynt.com) for a key.

<CodeGroup>
```bash curl
curl -s "https://integrations.bluprynt.com/assets/solana/EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v" \
  -H "Authorization: $BLUPRYNT_API_KEY"
```
```ts TypeScript
const res = await fetch(
  'https://integrations.bluprynt.com/assets/solana/EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v',
  { headers: { Authorization: process.env.BLUPRYNT_API_KEY! } },
)
if (res.status === 404) throw new Error('No verified asset at this address')
const asset = await res.json()
console.log(asset.business_details.business_name, asset.business_details.business_verified)
```
```python Python
import os, requests

res = requests.get(
    "https://integrations.bluprynt.com/assets/solana/EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v",
    headers={"Authorization": os.environ["BLUPRYNT_API_KEY"]},
)
if res.status_code == 404:
    raise LookupError("No verified asset at this address")
asset = res.json()
print(asset["business_details"]["business_name"])
```
