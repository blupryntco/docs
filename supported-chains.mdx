KYI verification is where an issuer signs to prove control of a token. It runs on every chain below. The **Public API `chain`** column lists the short slugs the [public lookups](/api/public/overview) accept; for any other chain use the CAIP lookup with a CAIP-2 namespace and reference, for example `eip155` and `1` for Ethereum.
